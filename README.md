# Lil-tabreed wa al-takyeef

English website for an AC and refrigeration shop in Riyadh, Saudi Arabia.

Brand name on the site: **للتبريد والتكييف**

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Configuration

Replace placeholders in `src/config/site.js` (phone, WhatsApp, address, hours).
